# My Finance Agent - Python理财助手

一个智能化的基金投资顾问系统，包含V5智能选基算法、自动数据获取、消息推送等功能。

## 🎯 核心功能

### 1. **V5智能选基系统** ⭐ 最新
- **防高位回调算法**：成功避免红利ETF高位回落导致的损失
- **多维度评分**：趋势30% + 距高点20% + 涨幅风险10% + 反弹15% + 估值15% + 位置10%
- **实时监控**：支持30+主流基金和ETF
- **智能推荐**：自动筛选最佳投资标的

### 2. **基金晨间投资报告**
- 📊 每日自动扫描30只主流ETF
- 🏆 智能筛选Top 10推荐
- 📱 微信/Telegram自动推送
- ⏰ 定时任务：交易日每天8:30

### 3. **实时监控系统**
- 💹 盘中实时监控涨跌幅
- 🛡️ 暴跌预警系统
- 📈 技术指标分析（MACD、RSI、布林带）
- ⚠️ 动态止损提醒

### 4. **持仓管理**
- 📝 交易日志自动记录
- 💼 持仓组合分析
- 🎯 置换建议生成
- 📊 累计盈亏跟踪

## 🚀 快速开始

### 1. 安装依赖

```bash
pip install -r requirements.txt
```

### 2. 配置Token

编辑 `config.py`，填入你的Token：

```python
# Tushare Token
TUSHARE_TOKEN = "你的Token"

# Server酱（微信推送）
SERVERCHAN_SENDKEY = "你的SendKey"
NOTIFY_METHOD = "serverchan"
```

### 3. 运行V5算法

```bash
# V5智能选基
python smart_selector_v5.py

# V4算法（对比）
python smart_selector_v4.py

# 查看持仓
python check_now.py
```

## 💡 常见问题

### Q: V5和V4有什么区别？
A: V5新增了"距高点距离评分"和"近期涨幅风险评分"，成功避免了高位追涨的问题。

### Q: 为什么有些基金V4推荐但V5不推荐？
A: 如果基金刚从6个月高点回落（距高点<10%），V5会标记为"高位回落"不推荐，避免买入即跌。

### Q: 如何查看历史交易记录？
A: 查看`trade_log_YYYYMMDD.md`文件，包含详细的持仓分析和操作记录。

### Q: 置换建议如何使用？
A: 查看`replacement_options_YYYYMMDD.md`，会给出具体的置换方案和理由。
